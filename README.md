<h1>ArkScrollHotbar</h1>

<p>
    Ark: Survival Evolved doesn't have a native option to control the hotbar (1-0 Keys) using the scroll wheel.
    ArkScrollHotbar adds this function to the game. This works for any game, but shouldn't be required in most <b>properly programmed</b> games.</br>
    The program works with a single python script (main.py) which "translates" mouse scrolling actions into the corresponding key input used for the hotbar.</br>
    In the Game, you need the hotbar slots bound to 1-0 number keys (like default) and have nothing bound to scroll up/down.</br>
    You start the app by double-clicking the "ArkScrollHotbar v1.0.bat" file. Once it says "RUNNING", it's running.</br>
    By default, the scrolling selection stops at the 7th hotbar slot, to leave 3 free slots for consumables and prevent accidentally using them. You can edit the min_pos and max_pos variables in main.py to adjust the scrollable part of your hotbar.
</p>
